# dotenvx set KEY_PLAIN value

<GuideHeading lead={description} />

```sh
$ touch .env

dotenvx set HELLO_PLAIN World
◇ set HELLO_PLAIN (.env)
```

Keys ending in `_PLAIN` are not encrypted by `dotenvx set` or `dotenvx encrypt`.
