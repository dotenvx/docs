# dotenvx get -ik

<GuideHeading lead={description} />

Pass `--include-key`, or its `-ik` alias. Glob patterns are supported.

```sh
$ echo "HELLO=World\nHOLA=Mundo\nGOODBYE=World" > .env

$ dotenvx get -ik "H*"
{"HELLO":"World","HOLA":"Mundo"}
```
