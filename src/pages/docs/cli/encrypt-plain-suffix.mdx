# dotenvx encrypt KEY_PLAIN

<GuideHeading lead={description} />

```sh
$ echo "HELLO=World\nHELLO_PLAIN=visible" > .env

dotenvx encrypt
◈ encrypted (.env)
```

`HELLO` is encrypted. `HELLO_PLAIN` stays plaintext.
