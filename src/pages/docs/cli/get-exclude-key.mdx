# dotenvx get -ek

<GuideHeading lead={description} />

Pass `--exclude-key`, or its `-ek` alias. Glob patterns are supported.

```sh
$ echo "DOTENV_PUBLIC_KEY=public\nHELLO=World" > .env

$ dotenvx get --format=eval-export -ek "DOTENV_PUBLIC_KEY*"
export HELLO='World'
```
