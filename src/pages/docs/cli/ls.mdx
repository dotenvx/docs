# dotenvx ls

<GuideHeading lead={description} />

```sh
$ dotenvx ls
├─ .env.production
├─ .env
└─ apps
   └─ backend
      └─ .env
```

Pass a directory to list `.env` files under that path.

```sh
$ dotenvx ls apps/backend
└─ .env
```
