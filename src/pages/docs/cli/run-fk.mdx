# dotenvx run -fk

<GuideHeading lead={description} />

```sh
$ cd apps/web

dotenvx run -f . -fk ../.. -- node index.js
```

Here the workspace uses its own `.env`, while `-fk ../..` loads the shared root `.env.keys`.
